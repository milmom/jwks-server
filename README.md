# JWKS-Server
AI contributions:
Throughout this project, Copilot was used mainly as a debugging and architectural assistant, although it wrote the starter code. It aided me in understanding the overall architecture of a JWKS server, including building the application in modular parts (key management, JWT issuance, and API handling). It also aided me in understanding how to implement RSA key pair generation, the association of kid values and expiration dates with keys, and how to ensure that expired keys were not included in the JWKS endpoint response but could still be used for the issuance of expired tokens. It also HEAVILY aided me in debugging environment-related issues on the UNT Linux servers (virtual environment issues, pip install, uvicorn run, port binding, and gradebot integration), Git and GitHub authentication issues (including the generation of a Personal Access Token and history merging), and understanding gradebot output to ensure that the API response format was compatible with the grader’s requirements
